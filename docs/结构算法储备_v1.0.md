# 结构算法储备接入说明 — 未来真 HTML 正文提取

> **日期**: 2026-08-10 · **定位**: 储备文档(C1)，不引入代码，明确未来接入路径
> **版本**: v1.0 · **状态**: 常备参考 · 更新于 2026-08-11
> **背景**: 当前 40 篇知乎是纯文本快照 → 结构算法(需 HTML 标签)全部用不上；
>          未来爬真 HTML 文章页(如掘金/CSDN 详情页)时才启用

---

## 一、为什么需要储备

当前清洗对纯文本用**规则词库**（`cleaning_rules.yaml`），这已足够。
但若未来爬**真 HTML 文章页**，HTML 里有导航/侧栏/正文的标签结构——
此时可借"结构特征算法"自动区分正文与样板（导航/广告/页脚），比词库更通用。

**原则**：结构算法是"规则词库的补充"，不是替代——两类噪音不同。

| 数据形态 | 用哪个 |
|---------|--------|
| 纯文本快照（当前知乎） | 规则词库（已有） |
| 真 HTML 文章页（未来） | 结构算法（本储备） |

## 二、候选算法对比

| 算法 | star | 语言 | 原理 | 特点 |
|------|------|------|------|------|
| **trafilatura** | 6.6k | Python | 标签统计 + 文本密度 + 语言模型 | ✅ **已装(Stage0)**，Apache-2.0，主力 |
| **dragnet** | 1.3k | Python | 特征工程 + 机器学习模型 | MIT，精度高但需模型/较重 |
| **jusText** | 822 | Python | 启发式(文本密度/标签分布) | 轻量(lxml)，纯启发式无模型，备选 |
| **boilerpipe** | 542 | Python | 经典样板去除算法 | 启发式，接口较老，备选 |

## 三、分工与降级链

```
未来 HTML 文章页
  → ① trafilatura (已装, 主力)          — favor_precision 提取正文
  → ② jusText (备选)                   — trafilatura 提取失败/为空时降级
  → ③ dragnet (强备选, 最后)            — 前两者都不够时(需模型)
```

**为什么 trafilatura 仍主力**：已装、效果好(40 篇测试验证)、favor_precision 去导航干净。
**jusText 作备选理由**：轻量(lxml 单依赖)、纯启发式无模型、822⭐ 验证充分，适合"快速降级"。
**dragnet 最后理由**：精度最高但需特征工程+模型，重，非首选。

## 四、接入路径（未来启用步骤）

1. **确认数据源**：爬虫抓到真 HTML 文章页（`is_html_like` 返回 True）
2. **trafilatura 优先**：已接好（`cleaning.py::extract_article`）
3. **失败降级 jusText**：
   - 装 `jusText` 到 trafilatura venv（`pip install justext`）
   - `extract_article` 里 trafilatura 返回空时，subprocess 调 jusText 提取
4. **极端场景 dragnet**：装模型化版本，独立 venv（较重）

> 注：上述步骤**现在不执行**（当前数据纯文本，用不上），仅记录路径。
> 未来出现真 HTML 数据源时，按此接入并走"数据形态分流(C2)"自动判断。

## 五、结论

- 结构算法**不需要现在装**——当前纯文本用不上，trafilatura 已覆盖未来 HTML 主需求
- 储备价值：**明确了"未来爬真 HTML 时怎么接"**，避免临时抓瞎
- 接入成本低：jusText 单依赖轻量，路径已探明，启用时按第四步执行即可

## 六、数据形态分流（已实现，触发机制）

清洗入口已能自动判断输入形态并路由（`cleaning.py::is_html_like` + `extract_article`）：

```
输入文本
  → is_html_like 检测
      ├─ 真 HTML 标签 → 走 trafilatura 提取正文 (engine=trafilatura)
      └─ 纯文本快照  → 走规则词库 (engine=plain)
```

- **边界已验证**：`>>广告<<`（<后非字母）、`C++`、含数字文本 → 均不误判为 HTML
- **40 篇知乎路由**：全部 plain（纯文本快照）→ 规则词库生效
- **未来真 HTML 数据**：自动走 trafilatura，失败可降级 jusText（第四步路径）
- **批量报告**：`clean_kb.py` 输出 `引擎: trafilatura N / plain N`，分流可见可验证

> 该机制让工作流**自适应数据形态**——纯文本、HTML、未来其他形态无需改引擎，自动选择正确路径。
