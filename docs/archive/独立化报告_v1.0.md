# 清洗工作流独立化报告

> **版本**: v1.0 · **状态**: 历史过程 · 归档于 2026-08-11
> **日期**: 2026-08-10 · **目的**: 把清洗工作流从爬虫项目 `_crawl` 内抽离，独立成可复用、可开源模块
> **方案**: B（目录分层 + 源码暂不拆单文件）

## 一、为什么独立化

- 清洗工作流是**通用清洗工具**（网页/文本/视频转写 → 干净文本），不只服务 BossJobAI
- 之后要**开源到别处**（像 media-to-notes），需要独立目录可整包带走
- 独立版本号 + 专属 CHANGELOG（v0.1.0 → v0.2.0 → v0.3.0）

## 二、从哪到哪

| | 原位置（_crawl 内） | 独立项目 |
|---|--------------------|---------|
| 清洗引擎 | `cleaner/cleaning.py` | `清洗工作流/cleaner/cleaning.py` |
| 批量入口 | `_crawl/tools/clean_kb.py` | `清洗工作流/cli/clean_batch.py` |
| 规则配置 | `_crawl/config/cleaning_rules.yaml` | `清洗工作流/rules/cleaning_rules.yaml` |
| 文档 | `_crawl/清洗工作流/` | `清洗工作流/docs/`（+ 根 README/CHANGELOG） |
| 验收 | `_crawl/清洗工作流/_acceptance.py` | `清洗工作流/tests/test_acceptance.py` |

## 三、独立项目结构（分层）

```
清洗工作流/                    # ① 根: 入口/依赖/配置
├── README.md                 # 使用手册
├── CHANGELOG.md              # 工作流版本(v0.1.0→v0.3.0)
├── requirements.txt          # pip 依赖(PyYAML/clean-text/snownlp/jsonschema)
├── .env.example              # 工具路径模板(开源用)
├── .env                      # 本机配置(不提交)
├── cleaner/                  # ② 源码: 清洗引擎
├── cli/                      # ③ 命令入口: clean_batch.py
├── rules/                    # ④ 规则数据(改规则不改代码)
├── tests/                    # ⑤ 测试: test_acceptance.py
├── docs/                     # ⑥ 文档: 方案/计划/记录
├── output/                   # ⑦ 输出: 知识库_clean/(运行时生成)
└── logs/                     # 日志(运行时生成)
```

## 四、解耦的依赖（upstream.config 2 处）

| 文件 | 解耦前 | 解耦后 |
|------|--------|--------|
| `cleaner/cleaning.py` | `from upstream.config import tool`（469/482/603行） | 读 `.env`（`TRAFILATURA_PY`/`PRESIDIO_PY`，`_load_env` 加载） |
| `cli/clean_batch.py` | `from upstream.config import KB` | 读 `.env` `CLEAN_KB` 或 `--input`；输出到 `output/知识库_clean` |

## 六、独立化过程发现并修复的 bug

| bug | 修复 |
|-----|------|
| 规则路径仍指 `config/`（旧结构）→ video 规则找不到 | 改为 `rules/cleaning_rules.yaml` |
| `KB` 在 import cleaner **前**赋值 → .env 未加载 KB 空 | main 里 import 后重读 `CLEAN_KB` |
| `--input` 相对路径歧义 | 转 `os.path.abspath` |

## 七、遗留说明

| 项 | 说明 |
|----|------|
| `.env` 本机路径 | 开源只发 `.env.example`，用户自行填 venv 路径 |
| venv 依赖 | trafilatura/presidio 独立 venv（`AAA.Tool/Python_Venvs/`），本机路径 |
| 源码未拆 | 方案 B：`cleaner/cleaning.py` 单文件（28KB），后续可考虑拆包（engine/rules/detection） |
| `_crawl` 已删原文件 | 独立项目为唯一来源；`upstream/config.py` 保留（爬虫用，清洗相关配置已移除） |

## 八、结论

**✅ 独立化完成**。清洗工作流从爬虫项目抽离为独立模块（`本地调研项目/清洗工作流/`），目录分层清晰（代码/规则/测试/文档/输出分离），解耦 upstream 依赖，14/14 验收通过，具备开源条件（`.env.example` 模板 + 独立 CHANGELOG）。
