## 二、为什么 AGPL-3.0 不构成传染

AGPL-3.0 的开源义务针对**衍生作品**（对 AGPL 代码的修改、或与 AGPL 代码合并成单一作品时，该作品须以 AGPL-3.0 发布）。

本项目对依赖库是**独立调用**而非合并：
1. 依赖通过 `pip install` 独立安装，运行时 `import` / `subprocess` 调用；
2. 不修改、不内嵌、不静态链接任何依赖库源码；
3. 因此依赖库保持其自身许可证（MIT/Apache-2.0），**不受 AGPL-3.0 传染**。

用 AGPL-3.0 发布**自研代码**、同时依赖宽松许可库，是业界标准做法（与 MediaWiki、GitLab 社区版等同型）。

## 三、代码自研性声明

- 引擎核心（`cleaning.py` 多动作规则 `_is_teaching_line` / `_is_garbled` / `merge_broken_lines` / `compress_repetition`、`clean_asr_json.py` 保结构清洗、`sentence_normalize.py`）均为本项目原创实现；
- `docs/调研/` 的 400 仓库调研报告是对第三方仓库的**评审观点**（未随开源发布，单仓库报告本地留存），非复制其代码；
- 无任何从第三方仓库直接摘录的源码段。
