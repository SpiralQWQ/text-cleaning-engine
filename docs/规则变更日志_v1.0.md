## 2026-08-11 · version 4 · 多动作区块（转写内容保护 R1）

**变更**：
- 新增 `protect_teaching` 区块：教学词表（`teaching_words`，课程专属词/专有名词）
- 新增 `compress_repeat` 区块：台词压缩阈值（`min_count: 3`）
- 新增 `watermark` 区块：界面水印阈值（`min_count: 30`）
- 新增 `garbled` 区块：乱码检测参数（`min_len: 2`）

**原因**：规则引擎从"布尔删"升级为"多动作"（delete/compress/protect/merge），支撑转写内容保护 A-E 五类问题（台词压缩保留/教学白名单/水印删除/乱码检测/续句合并）。

**注意**：
- 台词重复不再整行删除——由 `compress_repeat` 压缩为 `原文…[出现N次]`（教学强调保留）
- 教学短行由 `protect_teaching` 保护，乱码/水印删除前先豁免

## 2026-08-11 · version 3 · 新增视频界面水印正则（接口适配）

**变更**：
- `noise_regex` 新增 8 条视频界面水印/学习标签正则（行首锚定 `^`）：
  - `^坚持打卡`（水印：坚持打卡30天听力口语突飞猛进）
  - `^片名[：:]`（水印：片名：查莉成长日记）
  - `^知识点\d+`（学习标签：知识点12345/678/91011121314）
  - `^高手盲听` / `^初学看字幕`（学习标签）
  - `^纯英[文宇字]+幕$`（学习标签，覆盖 OCR 错别字"纯英文宇幕"）
  - `^爱说英语的福安` / `^爱悦英烫`（答主水印）

**原因**：接口适配（阶段0，对接上游转写工具产出）。实测发现短样本（4 帧示例）水印独立行 2 次 < "高频重复行"阈值 3 → 漏删。改行首正则后独立行水印必删。

**注意**：
- **行首锚定 `^`** 是关键——GLM 画面描述以"画面"开头，不会被误删
- **MILK/Dishuching/L-Lavndey/语的 等保留**——它们是画面里的教学英文（GLM 描述"家务分类 D-Dishwashing"），是教学短行不是噪音，对应问题3 的边界判断

## 2026-08-10 · version 2 · 新增 video_ocr 分组

**变更**：
- `noise_substr` 新增 `video_ocr` 分组（帧标记 `=====`、OCR 标签 `画面文字 OCR`、GLM 标签 `GLM画面理解`）
- 引擎 `cleaning.py`：新增"高频重复行"删除（整行重复≥3次 → 删，处理视频内重复水印，如"坚持打卡30天"×174）
- 引擎 `cleaning.py`：新增"标点乱码规范化"（`,,`→`,`、`..`→`.`、`??`→`?`、`,.`→`.`，处理 ASR 转写乱码）

**原因**：text-cleaning-engine 扩展"视频转写形态"（OCR+视觉 / ASR 音频转写），需识别视频特有噪音。

**注意**：
- 视频内重复水印（坚持打卡30天/片名/知识点等）**不放 noise_substr**——GLM 画面描述会提到这些界面文字，行含即删会误删描述；由"高频重复行"规则自动删
- 标点乱码规范化是通用归一化（对中文/英文都生效）
